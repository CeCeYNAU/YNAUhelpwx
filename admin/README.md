# 云小农智慧校园小程序 - Web版后台管理系统

## 快速开始

### 启动方式

直接在浏览器中打开 `admin/index.html` 文件即可使用后台管理系统，无需服务器环境。

```
双击 admin/index.html 或拖拽到浏览器窗口
```

## 功能模块

### 1. 数据概览（首页）

**功能说明：**
- 实时显示系统统计数据（用户数、待办事项、失物招领、论坛帖子）
- 可视化图表展示用户增长趋势和使用分布
- 数据自动从微信小程序 LocalStorage 同步

**操作指南：**
- 查看顶部四个统计卡片了解系统概况
- 柱状图显示最近7天的用户增长情况
- 饼图展示各功能模块的使用占比

### 2. 用户管理

**功能说明：**
- 查看所有已绑定用户信息（学号、姓名、学院、专业等）
- 添加新用户
- 删除用户记录
- 搜索和筛选用户

**操作指南：**
- **添加用户：** 点击右上角"添加用户"按钮，在弹出的模态框中填写信息后保存
- **搜索用户：** 在搜索框输入学号、姓名或学院进行模糊搜索
- **删除用户：** 点击用户行右侧的删除按钮，确认后删除

**数据字段：**
- 学号（必填）
- 姓名（必填）
- 学院
- 专业
- 年级
- 绑定时间

### 3. 待办事项管理

**功能说明：**
- 查看所有用户的待办事项列表
- 按状态筛选（未完成/已完成）
- 删除过期或无效待办

**操作指南：**
- 使用顶部筛选器切换显示全部/未完成/已完成
- 点击删除按钮移除待办事项
- 表格显示标题、内容、截止时间、所属用户等信息

### 4. 失物招领管理

**功能说明：**
- 浏览所有失物招领信息
- 网格卡片式展示，包含图片预览
- 按类型筛选（失物/招领）

**操作指南：**
- 使用筛选器查看失物或招领信息
- 卡片显示物品图片、标题、描述、联系方式等
- 点击删除按钮移除记录

**显示信息：**
- 物品图片（如有）
- 标题和详细描述
- 物品类型（失物/招领）
- 丢失/拾取地点
- 联系人和联系方式
- 发布时间

### 5. 论坛管理

**功能说明：**
- 查看所有论坛帖子
- 管理违规或不适当内容
- 查看发帖人信息

**操作指南：**
- 帖子列表显示标题、内容摘要、作者、回复数等
- 点击删除按钮移除帖子
- 支持按标题搜索

### 6. 活动管理

**功能说明：**
- 浏览校园活动信息
- 查看活动详情（时间、地点、人数限制等）
- 管理活动发布

**操作指南：**
- 卡片式布局展示活动封面图、标题、时间、地点
- 显示报名人数和剩余名额
- 点击删除按钮取消活动

### 7. 校园风景管理

**功能说明：**
- 管理校园风景图片库
- 查看图片描述和拍摄地点
- 上传新风景照片（需配合小程序端）

**操作指南：**
- 网格布局展示风景图片
- 显示图片标题、描述、拍摄地点
- 点击删除按钮移除图片

### 8. 系统设置

**功能说明：**
- 导出所有数据为 JSON 文件
- 清理本地缓存
- 重置系统数据
- 关于系统信息

**操作指南：**

**导出数据：**
1. 点击"导出数据"按钮
2. 系统自动生成包含所有业务数据的 JSON 文件
3. 文件自动下载到本地

**清理缓存：**
1. 点击"清理缓存"按钮
2. 系统将清除所有临时数据和缓存
3. 页面自动刷新

**重置数据：**
1. 点击"重置数据"按钮
2. 弹出确认对话框（此操作不可恢复）
3. 确认后清空所有业务数据并重新加载

## 技术架构

### 设计系统

采用 **Material Design 3** 设计规范：

**色彩方案：**
- 主色：`#2E7D32`（绿色）
- 次色：`#FFC107`（琥珀色）
- 错误色：`#B00020`（红色）
- 成功色：`#4CAF50`（绿色）

**阴影层级：**
- Elevation 1: 卡片、按钮默认状态
- Elevation 2: 悬浮状态
- Elevation 3: 侧边栏、顶部栏
- Elevation 4: 模态框、下拉菜单

**圆角规范：**
- 小圆角：8px（按钮、标签）
- 中圆角：12px（卡片、输入框）
- 大圆角：16px（对话框、大型容器）

### 数据存储

**数据来源：**
系统直接从微信小程序的 LocalStorage 读取数据，确保数据一致性。

**存储键值：**
- `boundUsers`: 绑定用户列表
- `userTodos`: 待办事项
- `lostAndFound`: 失物招领
- `forumPosts`: 论坛帖子
- `campusActivities`: 校园活动
- `campusScenery`: 校园风景

### 核心技术

**前端框架：** 原生 HTML/CSS/JavaScript（无依赖）

**图表绘制：** Canvas API（柱状图、饼图）

**响应式设计：** CSS Grid + Flexbox，适配桌面和平板设备

**交互模式：**
- Toast 提示：操作反馈
- 模态框：表单输入、确认对话框
- 平滑过渡：页面切换、元素显示/隐藏

## 常见问题

### Q1: 为什么看不到数据？

**A:** 确保已在微信小程序中使用过相关功能并产生了数据。后台管理系统从 LocalStorage 读取数据，如果小程序未产生数据，后台将显示为空。

### Q2: 如何同步最新数据？

**A:** 刷新浏览器页面即可重新从 LocalStorage 加载最新数据。

### Q3: 导出的数据文件在哪里？

**A:** 导出的 JSON 文件会下载到浏览器的默认下载目录，文件名格式为 `campus-data-YYYY-MM-DD.json`。

### Q4: 能否在手机上使用？

**A:** 当前版本针对桌面浏览器优化，建议在电脑或平板上使用以获得最佳体验。

### Q5: 修改数据后小程序端会同步吗？

**A:** 是的，后台管理系统直接操作 LocalStorage，所有修改会立即反映在小程序端。

## 开发扩展

### 添加新功能模块

1. 在 `index.html` 中添加新的侧边栏菜单项和页面容器
2. 在 `admin.js` 中实现数据加载和渲染函数
3. 在 `admin.css` 中添加专属样式（如需要）

### 修改图表样式

编辑 `admin.js` 中的 `drawUserChart()` 和 `drawUsageChart()` 函数，调整 Canvas 绘图参数。

### 自定义主题颜色

修改 `admin.css` 中的 CSS 变量：

```css
:root {
  --md-primary: #你的主色;
  --md-secondary: #你的次色;
  /* ... 其他颜色变量 */
}
```

## 注意事项

1. **数据安全：** 定期导出数据备份，避免误操作导致数据丢失
2. **浏览器兼容：** 推荐使用 Chrome、Edge、Firefox 等现代浏览器
3. **性能优化：** 数据量较大时（超过1000条），建议使用搜索和筛选功能提升浏览速度
4. **权限管理：** 当前版本无登录验证，建议仅在本地或受信任环境中使用

## 技术支持

如遇问题，请检查：
1. 浏览器控制台是否有错误信息
2. LocalStorage 中是否存在对应数据
3. 文件路径是否正确（admin 文件夹与小程序项目同级）
